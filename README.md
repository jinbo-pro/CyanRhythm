# 青律 CyanRhythm

一款**纯本地运行的桌面音乐播放器**——无云端服务、不联网，仅播放你电脑里的音频文件。没有广告，没有会员，没有与音乐无关的喧嚣，让听歌回归纯粹。

> 面向开发者的技术文档（架构、构建、源码结构等）请参阅 [DEV.md](./DEV.md)。

---

## 为什么会有「青律」？

我从小听音乐的环境一直很纯粹——从收音机、磁带、MP3，到功能机，再到安卓手机刚出来的那几年，听歌是一件很简单的事。那时候没有版权的束缚，下载下来就能随便听，每一首歌都真真切切地属于自己。

但时代变了。

如今的歌曲大多需要会员、需要版权才能完整聆听。这些倒也罢了，真正让我难以接受的是——那些年辛辛苦苦积攒下来的本地 MP3 文件，放进现在的在线听歌软件里，竟然会被标记成「VIP 歌曲」，只能试听短短几秒。

更让人无奈的是，现在的听歌软件早已不再纯粹：开屏广告、弹窗活动、购物、直播、社交……一个用来放歌的程序，被塞进了各种与音乐无关的东西，变得臃肿又厚重。

为了拯救那些陪伴我多年的本地音乐文件，也为了拥有一个干净、纯粹的听歌环境，我开发了「青律 CyanRhythm」。

## 核心功能

### 本地音乐导入 & 多目录管理
- 浏览电脑上的任意目录，一键导入音乐文件夹
- 导入过程实时显示进度（发现文件数、解析进度、成功 / 失败数）
- 支持格式：**mp3 / flac / wav / aac / m4a**
- 自动解析歌曲名、歌手、专辑、专辑艺术家、时长、发行年份、专辑封面
- 支持添加多个目录，每个目录可单独「更新」（重新扫描）或「删除」
- 文件数量无上限，大音乐库也能流畅浏览

### 播放器控制
- 播放 / 暂停、上一曲、下一曲
- 播放进度自由拖拽
- 音量调节、一键静音
- 三种播放模式：顺序播放 / 单曲循环 / 随机播放

### 播放列表 & 收藏
- 新建、删除、重命名自定义播放列表
- 内置「我的收藏」，爱心图标一键收藏
- 歌曲可随时添加到播放列表或从中移除

### EQ 均衡器 & 音频可视化
- 10 段均衡器，支持启用 / 禁用、增益调节、预设切换
- 播放详情页带有可视化动画（旋转黑胶 + 环形频谱 + 漂浮粒子）

### 歌词
- 自动按优先级获取歌词：**歌曲内嵌歌词** → **同名 .lrc 文件** → **在线 LRCLIB**
- 支持带时间轴的同步歌词与纯文本歌词
- 在线歌词服务地址可在设置中自定义

### 元数据编辑
- 直接修改音频文件的标签（标题、艺术家、专辑、专辑艺术家、年份、歌词、封面）
- 封面支持裁剪后再写入
- 可手动触发在线歌词匹配并写回文件

### 播放统计
- 记录每首歌曲的播放次数与累计播放时长
- 独立的统计视图，直观展示你的听歌数据

### 本地数据同步（备份 / 恢复）
- 将全部数据（歌曲、播放列表、统计、进度）备份到本地
- 支持按用户名分桶，可设置密码加密保护
- 可随时从备份恢复数据，覆盖本地

### 全局快捷键
- 播放 / 暂停、上一曲、下一曲（默认 `Space` / `←` / `→`，可在设置中自定义）

### 数据自动保存
应用关闭或重启后，会自动恢复你的全部数据：歌曲库、播放列表、播放进度、设置、统计数据等，无需重新配置。

## 使用流程

1. 启动应用后，点击侧栏底部「导入音乐」按钮，打开导入管理面板
2. 点击「添加目录」，在文件夹选择器中浏览（盘符 / 快捷入口 / 手动输入），选择存放音频的文件夹
3. 等待扫描完成，实时查看发现文件数与解析进度
4. 在「歌曲 / 专辑 / 歌手 / 文件夹」视图中浏览你的音乐库，点击即可播放
5. 可对已导入的目录执行「更新」（重新扫描）或「删除」（移除目录及歌曲）
6. 左侧侧边栏可新建 / 编辑 / 删除自定义播放列表；歌曲行内「+」加入列表，爱心图标收藏
7. 底部播放栏：播放控制、进度拖拽、音量、播放模式、EQ 均衡器入口
8. 点击播放栏可打开全屏播放详情页（频谱可视化动画）
9. 在设置面板中可调整：显示项（封面 / 专辑 / 序号 / 文件名等）、歌词服务地址、快捷键、数据同步、清空数据
